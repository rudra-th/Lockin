# Lockin v1.11.1 — Google sign-in on Android

**Released 5 November 2026**

A one-fix patch for the Android shell. 1.11.0 never registered Google with the
native authentication plugin, so tapping **Continue with Google** failed before
the account sheet appeared, with:

> google.com sign-in provider is not enabled. Make sure to add the provider to
> the 'providers' list in the Capacitor configuration.

## Fixed

- `capacitor.config.json` now lists `google.com` in
  `plugins.FirebaseAuthentication.providers`. The plugin's default list is empty,
  and the native bridge reads that list before it opens the Google sheet.
- `npx cap sync android` copied the setting into
  `android/app/src/main/assets/capacitor.config.json`; the release APK is rebuilt
  as **versionCode 211 / versionName 1.11.1**, so it installs over 1.11.0 without
  uninstalling.
- No web or extension behaviour changed; both follow the shared version line.

## Install

- **Web**: [lockin.surge.sh](https://lockin.surge.sh) — unchanged 1.11.0 shell
  plus the 1.11.1 cache version.
- **Android**: download `lockin-1.11.1-release.apk` from the release assets or
  the [public mirror](https://lockin.surge.sh/downloads/lockin-1.11.1-release.apk)
  and sideload it. Google sign-in needs the release SHA-1 registered in Firebase;
  see [`../android.md`](../android.md).
- **Extension**: unchanged; the 1.11.1 package is available from the
  [public mirror](https://lockin.surge.sh/downloads/lockin-extension.zip) for
  version parity.

## Verified

- `npm run check`, `npm run lint`, `npm test` (88/88).
- `assembleRelease` succeeds; the packaged
  `android/app/src/main/assets/capacitor.config.json` contains
  `"providers": ["google.com"]`.
